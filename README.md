# Task Management System

A responsive task management web application built using HTML, CSS, and JavaScript.

## Features

- User Registration
- User Login
- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Complete
- Local Storage Persistence
- Responsive Design
- Modern User Interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
